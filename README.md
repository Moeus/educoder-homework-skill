# educoder-homework-skill

一个用于完成头歌（EduCoder）课堂实训作业的 Codex skill。它会逐关读取题目与「代码文件」下拉菜单，确定要编辑的文件；在工程目录可见时阅读相关源码和测试文件；根据评测输入、预期输出、实际输出及错误信息修正答案，并核对每关的通关结果。具体操作规则见 [SKILL.md](./SKILL.md)。

## 一次实测

以下是用户提供的一次记录：在 Edge 浏览器中，完成[课堂作业第二页](https://www.educoder.net/classrooms/WZPF4KHQ/shixun_homework)原先未完成的 3 项作业，共 8 关。每关均经评测通关，刷新作业列表后显示：

| 作业 | 完成进度 |
| --- | --- |
| 博客系统 - 数据库设计 | 3/3 |
| 博客系统 - 登录注册界面 | 2/2 |
| 博客系统 - 系统简介与首页设计 | 3/3 |

运行环境为 Codex 的 `gpt-6-sol`（high），用时约 **11 分 30 秒**，消耗约 **7%** 的 Codex 额度。这是一次运行记录，不代表其他作业或环境的固定耗时与消耗。
